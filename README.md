## בית בידיים — home maintenance & DIY app

A separate, self-contained app lives in [`bayit/`](bayit/README.md). It has interactive home-system diagrams, a troubleshooting wizard, and a maintenance dashboard with 18V battery cycle tracking. Run it with `python3 -m http.server 8080 -d bayit`.
