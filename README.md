# Abeve

Two independent Hebrew (RTL) web apps, served by GitHub Pages from `docs/`:

| App | Path | What it is |
|---|---|---|
| **Tick (טיק)** | `docs/` (built from `src/app.html`) | Trading journal and risk app for futures and stock traders. Developers: [HANDOFF.md](HANDOFF.md). |
| **Tzalul (צלול)** | `docs/tzalul/` | Private, offline-first companion for quitting cannabis and personal recovery. Developers: [TZALUL.md](TZALUL.md). |

- Tick live: https://yasobe.github.io/Abeve/
- Tzalul (once this branch is merged into the Pages branch): https://yasobe.github.io/Abeve/tzalul/
