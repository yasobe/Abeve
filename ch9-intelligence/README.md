# מעבדת המשכל — פרק 9

אתר לימוד אינטראקטיבי בעברית לפרק 9, "משכל והערכת משכל", בספר *מבוא לפסיכולוגיה* (Gerrig & Zimbardo).

- **מכ״ם ריבוי סוגי המשכל של גרדנר**: דירוג מהיר או שאלון של 16 היגדים, עדכון חי, גרירת נקודות על המכ״ם, השוואה להדגשי בית הספר.
- **משחק התרחישים של סטרנברג**: שישה תרחישים יומיומיים, בחירת פתרון וזיהוי הרכיב (אנליטי, יצירתי, מעשי), ומשולש נטיות בסיום.
- **לוח המטרה**: חצים להמחשת מהימנות ותוקף, תרשים פיזור של מבחן חוזר, ועקומות נורמות ותקנון.
- מבחן קצר לתרגול עצמי.

קובץ HTML אחד, ללא תלויות פרט לגופנים מ־Google Fonts. לפתוח את `index.html` בדפדפן.
