# מעבדת המשכל — פרק 9

אתר לימוד אינטראקטיבי בעברית לפרק 9, "משכל והערכת משכל", בספר *מבוא לפסיכולוגיה* (Gerrig & Zimbardo, מהדורת האוניברסיטה הפתוחה). הנושאים מסודרים לפי סדר הפרק, ולכל אחד מצוינים העמודים בספר.

| נושא | עמ׳ | מה עושים |
|---|---|---|
| תולדות ההערכה | 441–443 | ציר זמן של 10 תחנות, מסין העתיקה ועד איום הסטריאוטיפ |
| מהימנות, תוקף ותקנון | 443–448 | לוח מטרה עם חצים, תרשים מבחן חוזר, עקומות נורמות ותקנון |
| מבחני מנת משכל | 448–456 | הנוסחה של טרמן, מיון תת־מבחני וקסלר, שלושת המעגלים של רנזולי |
| תיאוריות פסיכומטריות | 457–459 | מטריצת מתאמים של g (ספירמן), מיון נזיל/מגובש (קאטל), קוביית גילפורד |
| סטרנברג | 460–462 | 9 תרחישים: בחירת פתרון וזיהוי הרכיב, משולש הצלחה לפי רכיב |
| גרדנר | 462–464 | מכ״ם 8 סוגי משכל: מחוונים, שאלון או גרירה, דירוג חי של התוצאה |
| תורשה וסביבה | 465–476 | סימולציית שני עציצים (תורשתיות בין קבוצות), איום הסטריאוטיפ |
| יצירתיות | 477–479 | משימת "שימושים בלבנה" עם טיימר, הקשר בין משכל ליצירתיות |
| הערכה וחברה | 480–482 | שלוש סוגיות לחשיבה |
| מבחן לתרגול | 485–486 | 18 שאלות עם הסברים וקישור חזרה לנושא |

ההתקדמות וערכי המכ״ם נשמרים בדפדפן (localStorage).
